## 已確認規則

1. 同一名角色同一時間只能參與一場掛機戰鬥。
2. 角色加入任何隊伍後，不能另外進行單人掛機。
3. 即使隊長沒有戰鬥，隊員仍不能單獨掛機。
4. 隊伍掛機正常運作。
5. 角色離隊後，才恢復單人掛機資格。

隊伍引用與戰鬥占用必須分開檢查，不能只看隊長是否戰鬥。使用永久角色 ID 識別。

## 預計核對

- 第四槽：角色上限、舊四槽遷移、編組與裝備所有權。
- 互斥：招募、離隊、主角切換、單人入口、在線／離線工作及多分頁，共用權威資格檢查。
- 非同步安全：等待保存或結算後，再驗證角色 ID、隊伍版本及工作狀態；恢復工作保留原快照。
- 戰鬥占用：與工作建立、完成及恢復交易一致，防止兩個分頁同時啟動。不能僅以 UI 或 localStorage 阻擋。

## 尚需確認的邊界

- 隊長的單人入口與合法隊伍掛機如何區分。
- 同一角色能否同時被不同隊伍引用；禁止同時參戰不等於已決定編組也互斥。
- 離隊時舊離線工作仍未完成，如何先處理該工作再恢復單人資格，避免重複計時。
- 關閉分頁、失聯及占用恢復方式；不自行新增自動離隊或清除角色規則。

# 第二階段 A 第二批驗收報告

本批僅為開發預覽的技能事件模擬，尚未啟用正式三人離線掛機、正式收益或建築事件。不提交 commit。

接入怒氣生成／消耗、能量自然恢復、副手攻擊、毒與流血分組疊層及結算、箭矢恢復、寵物攻擊／增益／守護、MP 自然恢復與枯竭、元素與奧術狀態、治療、延遲餘光、聖域及護盾。普通怪物直接攻擊可觸發角色目前在線的閃避、招架反擊、低血量效果與牧師保命。

單怪模式只傳入一個存活敵人。需要三個實際目標的神聖新星護盾等條件不會取得額外補償；毒擴散也不會凭空增加敵人。

舊版未明訂間隔的 DOT 依在線戰鬥的 100 毫秒更新節奏處理；有明訂間隔的毒／流血依各自事件時間處理。不擅自統一為每秒結算。共振到期即使主動技能不能施放，也會結算一次超載釋放。

## 共用方法與修改檔案

- `tools/build-offline-shared-runtime.js`：從目前在線程式擷取 39 個處理器與 28 個政策；`--check` 檢查來源一致。
- `offline-shared-runtime.generated.js`：由上述來源產生的靜態隔離執行模組，沒有執行期 eval。後續在線相關程式變動必須重新產生。
- `offline-skill-events.js`：離線事件時鐘、獨立角色資源／冷卻、延遲事件與結果診斷。
- `offline-party-policy.js`：保留第一批預設基礎模擬；指定 `skills:true` 才使用第二批。
- `script.js`：開發預覽呼叫第二批；治癒術三秒餘光新增可快照的事件資料與一次結算保護，數值與延遲保持原值。
- `index.html`：載入隔離模組及事件驅動器。
- `tests/offline-*-skills.test.js`、`offline-skill-events.test.js`、`offline-skill-isolation.test.js`、`offline-shared-runtime-source.test.js`：技能、路線、來源一致與隔離測試。
- `tests/offline-skill-fixture.js`、`offline-skill-performance.js`：案例資料與明確執行的長時間效能測試。

開發預覽仍限本機 `offlinePartyStageA=1`，結果是診斷資料，不写入正式收益或角色戰鬥結果。

## 尚未接入及第三批銜接

- 共享生命／魔力／多人治癒藥水與同時使用的優先順序。
- 不死族復起、完整隊友死亡狀態清理／定時復活、主角敗北返回村莊。此版本主角死亡立即停止，隊友死亡後不繼續攻擊；完整復活流程留待第三批。
- 普通怪特殊技能、怪物 DOT／控制／自我治療／護盾與相應的玩家受傷事件。
- 特殊建築與區域壓制不加入第二階段 A；正式獎勵、領取防重及跨分頁結算留待第四批。

以上未接入流程會影響完整離線生存與收益，不能以本批模擬結果取代正式掛機結果。單怪不會觸發沒有實際目標的多目標效果，這是已確認規則。

## 驗證與效能口徑

35 個主動技能 × 六個等級，共 210 個施放案例；另外核對怒氣、能量、副手、毒血、箭矢、寵物、MP、元素、治療與護盾。1～3 人重跑結果一致，快照不變、常駐攻擊不重複套用、無真實計時器，死亡目標不接受延遲治療。第一批基礎與切分生命週期測試另行保留。

效能基準使用六級技能的劇毒盜賊、獸王獵人、神聖牧師及單隻普通怪，固定亂數。本機 Node 測試並非各裝置保證；長時間事件仍同步執行，正式啟用前需要處理主執行緒阻塞。每次測試均完整跑到指定時間，未因主角死亡提前退出。診斷事件有數量上限，非追蹤模式不累积每次攻擊明細。

最終版本測量：1 小時需 2,231 毫秒、20,566 次事件迴圈；12 小時需 21,956 毫秒、245,071 次事件迴圈。兩次完整結束且未死亡，診斷结果分別約 13.8 KB、14.0 KB。相同環境前一次量測為約 1.9 秒／17.3 秒，執行時間會受同時執行的回歸測試影響。

離線相關 12 個測試檔全部通過，包含第一批基礎與生命週期。完整頂層套件共 198 個測試檔，178 通過、20 失敗；這是測試檔數，210 個技能等級案例屬於其中的內部案例，不能混加成總測試檔數。

`arcane-mark-scaling`、`arcane-missile-experiment`、`arcane-missile-formal`、`chapter-three-36-rare-rune-playtest`、`chapter-three-facility-immortal-preview`、`chapter-three-facility-runtime`、`chapter-three-facility-visual-preview`、`chapter-three-late-runtime`、`chapter-three-suppression-ui`、`formal-combat-entry`、`headless-game-runtime`、`headless-progression-model`、`hunter-formal-combat-entry`、`mage-formal-consistency`、`priest-formal-combat-entry`、`rogue-formal-combat-entry`。

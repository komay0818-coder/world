# 遊戲資料查詢目錄

這個資料夾用來集中保存遊戲目前已實裝的資料，方便日後查找與核對。

## 資料文件

- [第一章裝備.md](第一章裝備.md)：第一章武器、鎧甲、皮甲與布甲。
- [第二章裝備.md](第二章裝備.md)：第二章武器與三套五部位防具。
- [材料與配方.md](材料與配方.md)：第一、二章材料、掉落率與製作配方。

## 閱讀說明

- 百分比屬性已轉成人類易讀格式，例如程式內的 `0.03` 顯示為 `3%`。
- 攻速是每秒攻擊次數；數值越高，攻擊越快。
- 本資料為查詢用文件，不會被遊戲直接載入。
- 實際遊戲設定仍以專案根目錄內的 `*-policy.js` 為準。

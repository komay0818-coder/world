# 第三章副手裝備

第三章只規劃綠色與藍色副手，不新增白色副手。所有副手沿用正式裝備詞綴系統；基本數值不計入詞綴數量。

| 品質 | 結構 |
| --- | --- |
| 綠色 | 基本數值＋1 條固定詞綴＋2 條隨機詞綴 |
| 藍色 | 較高基本數值＋2 條固定詞綴＋3 條隨機詞綴 |

| 裝備 | 品質 | 職業 | 基本數值 |
| --- | --- | --- | --- |
| 赤岩守衛盾 | 綠色 | 戰士 | 防禦 +15、格擋率 +5% |
| 赤岩軍團重盾 | 藍色 | 戰士 | 防禦 +20、格擋率 +6% |
| 荒原獵手箭筒 | 綠色 | 獵人 | 最大箭矢 12、每秒恢復 1.2 支＋隨機基本屬性一種 |
| 赤羽追獵箭筒 | 藍色 | 獵人 | 最大箭矢 12、每秒恢復 1.2 支＋隨機基本屬性一種 |
| 薩滿秘法書 | 綠色 | 法師／牧師 | 最大 MP +70、每秒回魔 +3 |
| 赤岩秘法典籍 | 藍色 | 法師／牧師 | 最大 MP +90、每秒回魔 +4 |

## 尚未定案

- 合法隨機詞綴清單
- 實際掉落地圖與掉落率
- 裝備圖片

上述項目完成前，第三章副手模板僅提供基本能力生成支援，維持不可正式掉落。刺客仍使用單手匕首作為副手，既有戰鬥規則不變。

## 箭筒隨機基本屬性

生成時等機率三選一，不占詞綴欄位，存入實例後不再重抽。

| 屬性 | 綠色 | 藍色 |
| --- | --- | --- |
| 攻擊力 | +10 | +15 |
| 暴擊率 | +3% | +5% |
| 暴擊傷害 | +8% | +12% |

基本屬性可與詞綴同屬性；盾牌與魔導書不使用此機制。舊存檔不補抽。

## 固定詞綴（暫定版，已接線）

| 裝備 | 固定詞綴 |
| --- | --- |
| 赤岩守衛盾 | 生命 +40 |
| 赤岩軍團重盾 | 生命 +50、受到傷害降低 3% |
| 荒原獵手箭筒 | 暴擊率 +6% |
| 赤羽追獵箭筒 | 暴擊率 +8%、對 Boss 傷害 +10% |
| 薩滿秘法書 | 魔力恢復 +20% |
| 赤岩秘法典籍 | 魔力恢復 +25%、技能冷卻恢復速度 +8% |

固定詞綴沿用既有 customFixed 機制；減傷以百分點彙總後與既有減傷累加，角色上限維持50%。隨機詞綴池維持空白，生成器不會補出尚未定案的隨機詞綴。基本屬性可與固定詞綴重複；詞綴間依既有屬性排重。

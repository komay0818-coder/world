# 第三章副手裝備

第三章只規劃綠色與藍色副手，不新增白色副手。所有副手沿用正式裝備詞綴系統；基本數值不計入詞綴數量。

| 品質 | 結構 |
| --- | --- |
| 綠色 | 基本數值＋1 條固定詞綴＋2 條隨機詞綴 |
| 藍色 | 較高基本數值＋2 條固定詞綴＋3 條隨機詞綴 |

| 裝備 | 品質 | 職業 | 基本數值 |
| --- | --- | --- | --- |
| 赤岩守衛盾 | 綠色 | 戰士 | 防禦 +16、格擋率 +5% |
| 赤岩軍團重盾 | 藍色 | 戰士 | 防禦 +21、格擋率 +6% |
| 荒原獵手箭筒 | 綠色 | 獵人 | 最大箭矢 12、每秒恢復 1.4 支 |
| 赤羽追獵箭筒 | 藍色 | 獵人 | 最大箭矢 13、每秒恢復 1.6 支 |
| 薩滿秘法書 | 綠色 | 法師／牧師 | 最大 MP +70、每秒回魔 +2.5 |
| 赤岩秘法典籍 | 藍色 | 法師／牧師 | 最大 MP +90、每秒回魔 +3 |

## 尚未定案

- 綠色副手的固定詞綴內容
- 藍色副手的兩條固定詞綴內容
- 合法隨機詞綴清單
- 實際掉落地圖與掉落率
- 裝備圖片

上述項目完成前，第三章副手模板維持不可生成、不可掉落。刺客仍使用單手匕首作為副手，既有戰鬥規則不變。

# 劇毒系第六次長期放置調整：瘟疫蔓延3層門檻

本輪只將 Lv6 瘟疫蔓延的保存條件由敵人死亡時至少2層 Poison 改為3層 Poison。第五版 Poison、Rupture、起始傷害、技能循環、冷卻及所有傷害乘區均未修改。

|---|---:|---:|---:|
| 遠古祭司 | 2.322秒 | 2.432秒 | 刺殺快4.74% |
| 聖殿執行者 | 3.562秒 | 3.650秒 | 刺殺快2.46% |
| 符文魔像 | 5.371秒 | 5.391秒 | 刺殺快0.38% |
| 聖殿石衛 | 8.131秒 | 8.585秒 | 刺殺快5.58% |
| 聖殿守護者 | 26.863秒 | 26.020秒 | 劇毒快3.14% |

單怪結果與第五版相同，確認本次跨怪條件調整沒有改變單怪強度。
